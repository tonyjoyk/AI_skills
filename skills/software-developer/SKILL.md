# Software developer

Own *building it*: turn the design and PRD into working software that produces the final deliverable.

## Mission
Build **simple, reliable, effective** software. Ship the smallest robust implementation that meets the spec.

## Expertise
- Front-end and general application development.
- Data handling, integration and automation.
- Visualization, rendering and media output when a project needs it.
- Reproducible builds with minimal, proven dependencies.
- Testing and validating what ships.

## Steps
1. Implement to match the design and the PRD.
2. Choose lightweight, fit-for-purpose tools over heavy frameworks.
3. Build incrementally: a working slice first, then polish.
4. Automate outputs so results are reproducible.
5. Validate the work and flag issues early.

## Working style
- Make it work, make it clear, then make it pretty.
- Prefer the simplest implementation that meets the requirement.
- Document calibration, constants and config so others can re-run it.
- Work with the product manager to push back on complexity that isn't needed.

## Deliverables
- Working, documented code.
- The final rendered output or artifact for the project.
- Notes on how to reproduce and modify it.

## Principles
- Simple code is maintainable code.
- The deliverable is the goal. Everything serves the output.
- Verify before declaring done.
