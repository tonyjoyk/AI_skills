# Final Comic Quality Checklist

## Editorial accuracy
- [ ] Purpose is clear.
- [ ] Important events and outcomes are present.
- [ ] Proposals, commitments, completed work, and plans are distinct.
- [ ] Parallel workstreams remain separate.
- [ ] No unsupported claims or invented quotations.
- [ ] Important caveats and dependencies are retained.
- [ ] The comic does not include every note indiscriminately.

## Copy
- [ ] Title, date, location, names, roles, and organisation spellings are correct.
- [ ] Technical terms are explained at first use.
- [ ] Each balloon has a clear speaker.
- [ ] Narration adds context instead of repeating dialogue.
- [ ] Numbers have clear labels and correct meanings.
- [ ] Units, denominators, periods, and status qualifiers are preserved.
- [ ] Text matches the approved script.
- [ ] No garbled, duplicated, or missing words.

## Characters
- [ ] Characters match approved references.
- [ ] Regional context is appropriate and not stereotyped.
- [ ] Similar characters are visually distinct.
- [ ] Hair, facial hair, glasses, skin tone, clothing, and build are consistent.
- [ ] Labels are correct and consistent.
- [ ] No accidental character merging.

## Comic craft
- [ ] Traditional rectangular panels and white gutters.
- [ ] Reading order is obvious.
- [ ] Balloon tails point to the correct speaker.
- [ ] Balloons do not obscure faces or important action.
- [ ] Panel proportions support the story.
- [ ] No infographic/poster drift.
- [ ] No unexplained floating labels or decorative icons.
- [ ] Closing panel adds value without needless repetition.

## Visual quality and delivery
- [ ] One consistent illustration style.
- [ ] Calm, restrained palette.
- [ ] Simple relevant backgrounds.
- [ ] Text legible at normal display size.
- [ ] Final image checked against approved copy.
- [ ] Remaining defects disclosed honestly.
